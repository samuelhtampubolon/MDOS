# mdos (backend)

Python package for Marketing Decision OS: the FastAPI server, analytics engines, strategy and journey simulators,
agents and database migrations. See the repository [README](../README.md) for setup and usage.

```bash
pip install -e ".[dev]"      # development
mdos                         # run the desktop mode (opens the browser)
pytest                       # tests (set TEST_DATABASE_URL to run them on PostgreSQL)
```
